# Chart edit mode

Chart edit mode turns a unit hierarchy into a configurable organizational chart. Select
the root unit in the ORBAT panel, then use **Chart settings** to control the page size,
layout, labels, symbols, connectors, and displayed equipment or personnel.

## Export a chart

Open the menu in the upper-right corner and select **Export chart**. Charts can be
downloaded as:

- **PNG** for documents and presentations. Choose 1×, 2×, or 3× resolution.
- **SVG** for lossless scaling and further editing in vector graphics applications.

The export area can preserve the selected page size or crop tightly around the chart
content with configurable padding. A white, transparent, or custom background can be
applied. The dialog shows the final pixel dimensions and estimated PNG working memory
before export; oversized PNG exports are blocked to avoid exhausting browser memory.

SVG exports use physical millimetre dimensions for the A-series page presets. Both
formats omit chart selection controls and debug overlays and include the chart title and
ORBAT Mapper export metadata.
